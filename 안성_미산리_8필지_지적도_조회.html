안성시 양성면 미산리 8개 필지

브이월드 지적도 조회 · 지도 원본 이미지 출력 도구

① API 인증키 입력

반드시 등록된 https://greenbms.co.kr에서 실행하세요. 인증키는 이 HTML 파일에 저장되지 않으며, 입력한 값은 브이월드 API 요청에만 사용됩니다. 브라우저 개발자 도구에는 요청 URL이 나타날 수 있습니다.

② 조회 대상 목록

번호지번조회용 필지고유번호(PNU)조회 결과

PNU는 미산리 법정리 코드(4155036032)와 지번을 결합한 조회용 값입니다. API 응답의 PNU와 대조하여 일치하는 필지만 인정합니다.

③ 원본 지적도 출력

인증키를 입력하고 조회 버튼을 누르세요.
브이월드가 제공하는 지도 이미지가 표시됩니다.

흰색 지도가 나오면 다른 출력방식을 선택해 다시 표시하세요. 필지별 조회를 반복하지 않고 동일한 원본 경계 범위를 사용합니다.

모든 필지 경계를 조회해 지도 범위를 정한 뒤 브이월드 WMS에서 한 장의 PNG를 직접 요청합니다. 이미지에 선, 지번, 강조색 등을 추가하거나 여러 이미지를 합성하지 않습니다. 지도에 표시되는 지적정보는 참고용이며, 법적 경계 확인에는 공식 지적자료가 필요합니다.

자료 출처: 국토교통부 브이월드 · 대상지: 경기도 안성시 양성면 미산리 · 본 도구는 데이터 응답을 임의로 수정해 지적도를 만들지 않습니다.
